# 移动端 UI 与性能验收（2026-09-15）

本次完成首页/控制台共用语言菜单，工作区内居中的资料与充值页，账户名、钱包余额及下拉箭头，轻量控制台动效，统一表单控件。购买页去掉步骤条，金额卡片支持即时选中、可中断的反馈动画及自定义金额校验；支付渠道与结算区重新排版。日志筛选整合成一个区域，应用筛选时保留界面；日期框全区域可打开主题日历，手机显示底部面板，日志类型使用主题下拉选项。

手机联系我们与在线客服为两个独立入口；登录注册页面使用文档滚动。控件提供键盘操作、焦点恢复和减少动态效果支持。通过浏览器检查 320、375、768、1440、2048 像素视口及中英文布局，当前相关功能测试与生产构建通过。新增日期测试覆盖跨月、时间范围、确认、取消、焦点返回及避免误提交外层表单；日志测试覆盖类型筛选和翻页。

## 测试方式

PageSpeed 网站连接超时，官方匿名 API 返回 429（当日配额为 0），因此使用 Lighthouse 13.4.1 官方 CLI 的移动端默认模拟，在公网 URL 上测生产构建。不是 PageSpeed 网站生成的官方在线报告，也没有真实用户 CrUX 数据。

公网只读预览通过 localhost.run 隧道提供，控制台为明确标注的示例账号与数据，禁用付款和写操作。它不包含真实账号后端的延迟。浏览器到公网隧道还经过本机代理；HTTP/1.1 及单请求约 0.8 秒的往返延迟明显影响分数。站点实际部署效果必须在正式域名复测。

## 按结果修复

- 登录检查与控制台资源加载并行，构建时预加载当前路由需要的资源；CSS 只提前下载，保留原有应用顺序。
- 日志、资料改用轻量控件，去掉两页对 Semi UI 的加载依赖，并合并短小模块以减少串行请求。日志页首次加载不再下载约 98 KB 压缩 JS 和 75 KB 压缩 CSS 的 Semi UI 包。
- ECharts 按图表可见性加载、按需注册、复用实例；不在首页和认证页面加载。新增动效不依赖动画库，动画结束不参与金额/筛选状态的正确性。
- 修复图标请求 404、标题层级、对比度与语言/账户可访问名称不匹配；测量页面无控制台错误，布局偏移结果见表。

## 剩余成本与上线检查

- 隧道的首字节时间与 HTTP/1.1 连接排队不能通过 CSS 修复。正式静态服务应启用 HTTP/2 或 HTTP/3、gzip/Brotli 与带指纹资源的长缓存，HTML 重新验证；现有配置示例见 static-cache.nginx.conf。
- Tidio 的脚本、样式和通知音频仍有流量成本，报告完整计入。若要继续压缩第三方体积，需要在 Tidio 后台审核实际启用的功能。
- ECharts 约 190 KB gzip，仅图表可见时加载。需要图表功能，因此未以静态假图替换。
- 本次没有推送或部署。开发预览仍是 http://127.0.0.1:5173 ，接口代理目标为 https://pay.ztoken.cc 。
